README THEME NOTES
==================

1. Put README.md at the root of your GitHub profile repository.
2. Put the entire "assets" folder beside README.md.
3. GitHub README files do NOT allow arbitrary JavaScript, CSS, custom mouse cursors, or DOM event handlers.
4. The animated enemy and cursor-like interaction are therefore implemented as lightweight animated GIF assets, which GitHub supports.
5. The visual style is original anime/cyberpunk-inspired art rather than a copyrighted anime character.
